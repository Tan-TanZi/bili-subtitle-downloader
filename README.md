# B站字幕下载器

一个用于 [B站](https://www.bilibili.com) 的油猴脚本：分析当前视频的字幕，一键下载为 **TXT 纯文本** 或 **SRT 标准字幕文件**。

同时支持 **AI 生成字幕** 和 **UP 主上传的字幕**。

- 版本：1.0.0
- 适用页面：`www.bilibili.com/video/*`、`www.bilibili.com/bangumi/play/*`
- 许可证：MIT

---

## 功能

- 🔍 **一键分析**：列出当前视频的全部字幕，标明是「AI字幕」还是「用户上传」
- ⬇️ **两种格式导出**：每条字幕都能单独下载 TXT（纯文本）或 SRT（带时间轴）
- 🎛 **两种字幕来源可自选**：网络抓取 / 主动请求，可单独使用，也可两路并用取并集
- 🖱 **悬浮按钮**：可随意拖动，面板跟随显示，不遮挡播放器
- 🔀 **自动跟随切换**：SPA 切换到其它视频或分 P 时自动重置，不会串台
- 🪶 **轻量**：无第三方依赖，纯原生 JS

## 安装

1. 给浏览器安装脚本管理器：[Tampermonkey](https://www.tampermonkey.net/)（篡改猴），其它兼容的管理器也可（Violentmonkey 等）。
2. 安装本脚本，二选一：
   - **一键安装**：点击 [安装脚本](https://github.com/Tan-TanZi/bili-subtitle-downloader/raw/main/bili-subtitle-downloader.user.js)
   - **手动安装**：打开管理器的「添加新脚本」，把 `bili-subtitle-downloader.user.js` 的内容整段粘贴进去，保存。
3. 打开任意 B站视频页，右下角出现蓝色悬浮按钮即安装成功。

> 安装后如果没显示按钮，刷新一次页面；仍然没有的话检查脚本是否启用、以及地址是否匹配（只对视频页和番剧播放页生效）。

## 使用方法

1. 打开视频，点击右下角的**悬浮按钮**展开面板。
2. 按需勾选**字幕来源**（默认只勾「网络抓取」，详见下一节）。
3. 点击 **🔍 分析字幕**。
4. 面板列出所有字幕，点击某条右侧的 **TXT** 或 **SRT** 即可下载，文件名形如 `视频标题_P2_中文（中国）.srt`。

悬浮按钮和面板都可以拖动，按钮位置即时改变，面板贴着按钮弹出并自动避开屏幕边缘。

## 两种字幕来源的区别

面板里的开关决定脚本从哪里拿字幕列表：

| 来源 | 原理 | 优点 | 需要满足的条件 |
| --- | --- | --- | --- |
| **网络抓取**（默认） | 监听播放器自己发出的请求，读取其中携带的字幕列表 | 不额外发请求、最稳定、不会被风控 | 必须**先在播放器里开启过一次字幕**，才会产生可抓取的请求 |
| **主动请求** | 脚本主动调用 B站播放器接口查询 | 不需要手动开字幕 | 未登录时拿不到 AI 字幕，频繁点击可能触发风控 |

- 只勾一个 → 只用那一路。
- 两个都勾 → 结果取并集，最全（例如接口里没返回、但播放器请求里有的 AI 字幕也能列出来）。
- 一个都不勾 → 无法分析，会直接提示。

> 💡 建议：平时用默认的「网络抓取」；如果打开面板发现没抓到字幕，再勾上「主动请求」补一次。

## 输出格式

**TXT（纯文本）**

一段字幕一行，不含时间轴；文件带 UTF-8 BOM，Windows 记事本打开不会乱码。

```text
嗨 我是vk
这是我的实体AI系列的第一集
```

**SRT（标准字幕文件）**

带序号和时间轴，可直接导入 PotPlayer、VLC、Premiere 等：

```srt
1
00:00:06,080 --> 00:00:07,910
嗨 我是vk

2
00:00:08,490 --> 00:00:12,650
这是我的实体AI系列的第一集
```

## 工作原理

1. 脚本在 `document-start` 阶段（早于页面脚本）通过 `unsafeWindow` 挂载 `fetch` / `XMLHttpRequest` 的监听，捕获两类请求：
   - 播放器信息接口 `/x/player/(wbi/)v2` → 从中解析出字幕列表 `data.subtitle.subtitles`
   - 字幕文件 `*/bfs/ai_subtitle/*.json`、`*/bfs/subtitle/*.json` → 作为兜底记录
2. 点击「分析字幕」时，如勾选了主动请求，则调用 `x/player/wbi/v2`，失败回退 `x/player/v2`，再失败用 `GM_xmlhttpRequest`；结果与抓取到的数据合并去重。
3. 下载时拉取字幕 JSON（结构为 `body: [{ from, to, content }]`），转换成 TXT / SRT 后用 `Blob` 触发浏览器下载。

去重按「类型（AI/普通）+ 语言」判定，而不是按文件地址——因为 AI 字幕每次返回的地址可能不同。

## 常见问题

**Q：点「分析字幕」没有结果？**

- 只用「网络抓取」时：请先在播放器右下角**开启一次字幕**，再点分析；或勾选「主动请求」。
- 仍未登录 B站：AI 字幕列表接口不会返回内容，请先登录。
- 也可能该视频确实没有字幕。

**Q：为什么只有用户上传的字幕，没有 AI 字幕？**

AI 字幕需要登录才会返回；另外并非所有视频都生成了 AI 字幕。

**Q：下载的 TXT 打开是乱码？**

TXT 已带 UTF-8 BOM。若某些老旧编辑器仍异常，用 VS Code / 记事本以 UTF-8 打开即可。

**Q：番剧能下载吗？**

支持 `bangumi/play` 页面，但能否拿到字幕取决于该剧集本身是否提供（多数正版番剧没有可提取的字幕）。

**Q：会不会封号 / 风控？**

脚本只读取公开的字幕接口和已发出的请求，不发送任何账号数据。但请避免短时间内高频点击「主动请求」，那属于额外请求行为。

**Q：脚本会上传我的数据吗？**

不会。脚本没有任何统计、上报、外链请求，所有数据都在你本地浏览器里处理。

## 权限说明

| 声明 | 用途 |
| --- | --- |
| `GM_xmlhttpRequest` | 跨域拉取字幕文件（`fetch` 被 CORS 拦下时的兜底） |
| `unsafeWindow` | 读取页面里的视频信息（`__INITIAL_STATE__`）、挂载页面请求监听 |
| `@connect api.bilibili.com` | 允许请求 B站播放器接口 |
| `@connect aisubtitle.hdslb.com` | 允许请求字幕文件 |

脚本不使用 `GM_setValue` / `GM_getValue` 等存储，也不注册菜单命令，不写入任何持久化数据。

## 已知限制

- 仅匹配 `www.bilibili.com/video/*` 与 `www.bilibili.com/bangumi/play/*`，合集页、列表页、第三方内嵌播放器不支持。
- 「主动请求」使用的是未签名的播放器接口，B站若收紧校验可能失效；此时「网络抓取」不受影响，仍可正常使用。
- 若 B站调整响应字段（`data.subtitle.subtitles` 或 `body[].from/to/content`），需要同步更新脚本。
- 只下载字幕，不下载视频、音频、弹幕。
